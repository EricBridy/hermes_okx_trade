================================================================
  Hermes v10 部署包  —  上传整个文件夹即可
================================================================

文件夹里 8 个文件全部上传到服务器 /tmp/hermes_v10/ 即可：

  hermes_v10_brain.py      学习大脑
  hermes_v10_okx.py        OKX 客户端 (REST + WebSocket)
  hermes_v10_signals.py    三个信号生成器 (LIQ / FR / MR)
  hermes_v10_executor.py   下单 / 平仓
  hermes_v10_main.py       主程序入口
  test_v10_brain.py        单元测试
  deploy_v10.sh            自动部署脚本（上传后跑这个）
  manage_v10.sh            日常管理脚本（部署后用这个）


================================================================
  上传方法（在 Windows PowerShell 里执行）
================================================================

  cd e:\Users\xwcEr\Desktop\hermes_okx_trade-7.8\hermes_v10_release

  scp * root@<你的服务器IP>:/tmp/hermes_v10/

  注: 如果 /tmp/hermes_v10/ 不存在，先 ssh 上去 mkdir：
      ssh root@<IP> "mkdir -p /tmp/hermes_v10"


================================================================
  服务器上一键部署
================================================================

  ssh root@<你的服务器IP>
  cd /tmp/hermes_v10
  chmod +x deploy_v10.sh manage_v10.sh
  ./deploy_v10.sh

  脚本会自动：
    1. 检查 Python 3.11
    2. 检查 OKX 配置 ~/.okx/config.toml
    3. 提示你停掉 v82 (如果还在跑)
    4. 备份旧文件到 ~/.hermes/backup/v82_<时间戳>/
    5. 复制 v10 文件到 ~/.hermes/scripts/
    6. 跑单元测试 (必须看到 ALL TESTS PASSED)
    7. 主模块 import 测试


================================================================
  部署成功后启动
================================================================

  cd ~/.hermes/scripts

  # 第一次先前台跑，确认能正常启动
  /root/.local/bin/python3.11 hermes_v10_main.py
    （看到 "instruments cached / universe refreshed / [ws] connected"
      就说明启动成功；按 Ctrl+C 停掉）

  # 切到后台
  ./manage_v10.sh start


================================================================
  日常管理命令
================================================================

  ./manage_v10.sh start     后台启动
  ./manage_v10.sh stop      优雅停止 (自动保存大脑)
  ./manage_v10.sh restart   重启
  ./manage_v10.sh status    看状态：进程 / 持仓 / 大脑简况
  ./manage_v10.sh logs      实时看日志 (Ctrl+C 退出)
  ./manage_v10.sh tail      看最近 50 行
  ./manage_v10.sh stats     交易统计：胜率 / 各信号表现 / 最近10笔
  ./manage_v10.sh brain     大脑详情：特征权重柱状图 / Brier / Kelly
  ./manage_v10.sh trades    最近 20 笔交易明细
  ./manage_v10.sh help      帮助


================================================================
  冷启动期说明（重要）
================================================================

  第一天大脑没数据，会以 p_win≈0.5 的中性预测，
  以最低 Kelly 仓位 (10%) 谨慎下单。

  约 30-50 笔交易后，模型开始能区分好坏候选。
  约 150-200 笔后，特征权重才会稳定。

  这期间盈亏可能微负，是正常的"学习成本"，
  不要因为头几天没赚钱就停掉它，那会前功尽弃。
