# hermes_okx_trade

OKX 永续合约自动剥头皮交易机器人 v4.2 — 多仓并行版

## 概述

基于 **EMA 均线交叉 + ADX 趋势强度** 的自动化短线交易系统，针对 OKX USDT-SWAP 永续合约市场。系统全量扫描 240+ 个合约品种，筛选出强趋势信号后自动开仓、挂止盈止损，并实时监控持仓状态。

## 核心特性

- **全市场扫描**：每 15 秒扫描全部 OKX USDT-SWAP 合约（240+），按 24h 成交量排序取 Top 40
- **多仓并行**：最多同时持有 2-5 个仓位（可配置），提高信号捕获率
- **EMA + ADX 信号系统**：1m 和 5m 双时间框架 EMA9/21 交叉确认趋势方向，ADX(14) > 20 确认趋势强度
- **三重止盈止损保护**：每个仓位自动挂 TP / SL / CRASH 三个 algo 订单，挂单失败则强制平仓
- **裸仓安全检查**：每轮扫描前验证所有持仓都有 algo 保护，发现裸仓立即平仓
- **24/7 不间断交易**：默认全天候运行
- **限流容错**：API 请求自动重试（3 次，1.5s 递增间隔），仓位间 5s 错开避免 OKX 限流

## 策略逻辑

### 信号筛选（4 层过滤）

| 层级 | 条件 | 说明 |
|------|------|------|
| 1 | EMA9 > EMA21 (1m AND 5m) | 双时间框架趋势同向确认 |
| 2 | ADX(14) > 20 | 确认有趋势（非震荡市） |
| 3 | Vol > 0.3% | 5m K 线平均振幅 > 0.3%，保证足够波动 |
| 4 | 最低价格 > $0.001 | 排除超低价币（TP/SL 精度不足） |

### 开仓流程

1. 按 volatility 降序排列合格信号
2. 取 Top N（N = 最大持仓数 - 当前持仓数，上限 3）
3. 每个仓位等额分配资金
4. 串行开仓（5s 间隔避免限流）：
   - 设置杠杆（cross 模式）
   - 市价开仓
   - 查询持仓确认成交
   - 并行挂 TP / SL / CRASH 三个 algo 订单
   - 验证挂单成功，否则强制平仓

### 持仓监控

每个仓位实时监控，满足以下任一条件立即平仓：

| 条件 | 阈值 | 说明 |
|------|------|------|
| 浮盈 > 0.2% × 名义价值 | $0.0x 级别 | 超短线落袋为安 |
| 浮亏 > 0.7% | -0.7% | 止损砍仓 |
| 横盘 > 5 分钟且波动 < 0.15% | 300s | 时间止损，释放资金 |

### 风控机制

- **连亏暂停**：连续亏损 3 次后暂停 30 分钟
- **品种冷却**：同一品种平仓后 5 分钟内不再开仓
- **跳过品种**：特定问题品种加入黑名单（`SKIP_SYMS`）
- **盈亏比**：TP 1.05% / SL 0.7% ≈ 1.5:1

## 快速开始

### 1. 配置 OKX API

创建 `~/.okx/config.toml`：

```toml
[default]
api_key = "YOUR_API_KEY"
secret_key = "YOUR_SECRET_KEY"
passphrase = "YOUR_PASSPHRASE"
```

### 2. 运行脚本

```bash
# 前台运行（可看日志）
python3 v4_scalping.py

# 后台运行
python3 v4_scalping.py > /dev/null 2>&1 &
```

### 3. 查看交易日志

```bash
tail -f ~/.hermes/scripts/v4_trades.log
```

### 4. 停止脚本

## 已知问题与限制

1. **OKX API 限流**：认证 API 约 20 次/2 秒，开仓流程含 6 个 API 请求，需错开执行
2. **小资金限制**：$10-15 本金下每单利润微薄（$0.05-0.15），手续费占比高
3. **EMA 信号延迟**：EMA 是滞后指标，在快速反转行情中可能来不及反应
4. **极端低价币**：如 FLOKI（$0.00003x），TP/SL 差价低于 tick size 导致挂单失败
