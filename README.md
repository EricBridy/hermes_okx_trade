# hermes_okx_trade

OKX 永续合约自动化交易系统

## 当前版本：v7.8 — EMA/ADX/BB/ROC/Stoch多维过滤 + 快速止损

基于 **2仓位独立管理 + 双通道策略 + 多维度技术指标过滤** 的智能交易系统，针对 OKX USDT-SWAP 永续合约市场。

## 核心架构

```
┌─────────────────────────────────────────────────────────────┐
│                    数据采集层                                  │
│  OKX行情(80品种) + 资金费率(80) + K线(1m/5m/15m)              │
│  Binance Web3链上数据(6维度，60秒刷新)                         │
└───────────────┬─────────────────────────┬───────────────────┘
                │                         │
    ┌───────────▼───────────┐   ┌────────▼────────────┐
    │   通道A候选队列       │   │   通道B候选队列      │
    │   (极端FR+多空)       │   │   (评分≥10,顺势)     │
    │   Stoch过滤           │   │   EMA+量能+Stoch     │
    │   排序: score降序     │   │   排序: score降序    │
    └───────────┬───────────┘   └────────┬────────────┘
                │                         │
    ┌───────────▼─────────────────────────▼────────────┐
    │              2个独立仓位                            │
    │   仓位1: 通道A独占(极端FR) — 40%资金              │
    │   仓位2: 通道B独占(动量顺势) — 30%资金            │
    └────────────────────────────────────────────────────┘
```

## 策略逻辑

### 通道A：极端FR反向（仓位1独占）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 资金费率 | 0.05% < \|FR\| < 1% | 极端费率 = 散户集中方向 |
| 方向 | FR<0做多 / FR>0做空 | 多空兼顾 |
| 放量 | > 均量130% | 确认主力行动 |
| ADX | < 40 | 趋势过强做空危险 |
| BB宽度 | > 1.5% | 太窄无空间 |
| ROC | 做空需<0 | 价格已在跌才做空 |
| RSI | 做多<70 / 做空>30 | 避免追极端 |
| **v7.8 Stoch** | 做多<80 / 做空>20 | 与RSI双保险 |
| 仓位 | 40%资金 | 仓位1独占 |

### 通道B：动量顺势评分（仓位2独占）

| 评分要素 | 分值 | 说明 |
|----------|------|------|
| 5m涨跌幅度 | 1-3分 | >0.5%=1, >1%=2, >2%=3 |
| 1m放量倍数 | 1-3分 | >1.5x=1, >2x=2, >3x=3 |
| 1m趋势一致性 | 1-2分 | 连涨/跌>10根=1, >12根=2 |
| 链上信号 | 0-11分 | 6维度（见下方） |
| FR方向一致 | +1分 | FR与趋势同向 |
| 15m趋势强度 | +1分 | 5m和15m同向 |
| 5m连续确认 | +1分 | 最近2根5m同向且幅度>0.2% |

- **触发**：综合评分 ≥ 10（满分22）
- **方向**：顺势（涨做多，跌做空）
- **仓位**：30%资金，仓位2独占

### v7.8新增过滤（基于v7.6复盘数据）

| 改进 | v7.7 | v7.8 | 逻辑依据 |

| Stochastic时机 | 无 | >80不做多，<20不做空 | 避免追极端位置 |
| 评分门槛 | ≥8 | ≥10 | 过滤弱信号 |
| 快速止损 | 8分钟 | 4分钟 | 动量不走=方向错 |
| 追踪激活 | 1.5% | 1.0% | 提前锁定利润 |
| 追踪距离 | 0.8% | 0.6% | 收紧保护利润 |

### 噪音过滤（一票否决）

| # | 过滤器 | 否决场景 |
|---|--------|----------|
| 1 | 15m趋势冲突 | 5m涨但15m跌 → 不做多 |
| 2 | RSI>70超买 | 超买区做多 → 否决 |
| 3 | RSI<30超卖 | 超卖区做空 → 否决 |
| 4 | 1m反转检测 | 做多时3根1m全阴 → 正在反转 |
| 5 | 动量衰减 | 3根5m涨跌幅递减 → 势头已消 |
| 6 | 量价背离 | 价涨量缩/价跌量缩 → 假突破 |
| 7 | **v7.8** EMA排列 | 做多但EMA12<EMA26 → 无趋势骨架 |
| 8 | **v7.8** 5m量能 | 近期5m量<均值×1.1 → 资金未参与 |
| 9 | **v7.8** Stochastic | 超买区做多/超卖区做空 → 追极端 |

### 持仓管理

| 机制 | 阈值 | 说明 |
|------|------|------|
| TP | 3% | OKX algo单自动触发 |
| SL | 1.5% | OKX algo单自动触发 |
| 追踪止损 | 浮盈≥1%激活，回撤0.6%触发 | 程序主动平仓 |
| 紧急止盈 | 浮盈≥6% | 程序主动平仓 |
| 快速止损 | 4分钟且浮盈<0.5% | 程序主动平仓 |
| 浮盈宽限 | 4分钟+浮盈0~0.5% → 再给1分钟 | 程序主动平仓 |
| 裸仓保护 | 持仓无TP/SL挂单 | 立即强制平仓 |
| 连亏暂停 | 连续亏3单 | 暂停30分钟 |
| 换仓冷却 | 30分钟 | 防止频繁换仓 |
| 品种冷却 | 20分钟 | 同一品种不重复 |

### 换仓原则

```
❌ 不换仓：候选评分比持仓高
✅ 只换仓：持仓的开仓理由已经不存在了

通道A：FR消失或变正 → 换仓
通道B：方向反转或评分归零 → 换仓
换仓冷却：30分钟内不重复换仓
```

- **Python 3.8+**
- **依赖**：requests（无额外依赖）

- **服务器**：轻量级，2核2G即可

## 快速开始

### 1. 配置 OKX API

创建 `~/.okx/config.toml`：

```toml
[default]
api_key = "YOUR_API_KEY"
secret_key = "YOUR_SECRET_KEY"
passphrase = "YOUR_PASSPHRASE"
```

### 2. 运行

```bash
python3 v78_yao_hunter.py
```

### 3. 查看日志

```bash
tail -f ~/.hermes/scripts/v78_trades.log
```

### 4. 停止

```bash
pkill -f v78_yao_hunter
```
